# Метод Ремизова: постановка и проверка изменений

## Постановка

- L = a∂² + b∂ + c_R на ℝ. Уравнение a y″ + b y′ + (c_R − λ) y = −g_R ⇔ (λ − L) y = g_R.
  Связь с обычной формой: c = c_R − λ, g_R = −g.
- Искомое решение — ограниченное на ℝ: y = (λ − L)⁻¹ g_R = ∫₀^∞ e^{−λt} e^{tL} g_R dt. Это не задача Коши.
  Решение совпадает с решением IVP, только если точное решение ограничено на ℝ
  (в датасете — компактный носитель) и y0, v0 взяты из него.
- Условия (RemizovProblem, `_problem_conditions_valid`): 0 < a_lower ≤ a ≤ a_upper, |b| ≤ B, |c_R| ≤ C
  на всей ℝ (`bounds_certification="analytic"`, `bounds_domain="all_real_x"`), λ > C, gap = λ − C.
  Коэффициенты вычисляются далеко за пределами [x_target_min, x_target_max].
- Первоисточник в проекте отсутствует; точные условия теоремы не сверены.

## Аппроксимация

- S(τ)u(x) = ¼u(x+2√(a(x)τ)) + ¼u(x−2√(a(x)τ)) + ½u(x+2b(x)τ) + τ·c_R(x)·u(x).
- В S входит c_R, не c. λ в S не входит: только в вес e^{−λt} и в T. Знак дрейфа «+».
- Для гладких u: S(τ) = I + τL + O(τ²); ‖S(τ)‖∞ ≤ 1 + τC (неотрицательные веса с суммой 1).
- f_{n,T}(x) = ∫₀ᵀ e^{−λt} [S(t/n)ⁿ g_R](x) dt, T = max(0, log(2/(gap·tail_eps))/gap).
- Реализация: `CubicSpline(extrapolate=False)` на равномерных сетках; рабочая область
  [x_min − (n−k)·d_max, x_max + (n−k)·d_max], d_max = max(2√(a_upper·T/n), 2·B·T/n), без граничных условий;
  Gauss–Legendre на [0, T] с удвоением Nt; затем dx/2 с полным пересчётом квадратуры.

## Источники погрешности

1. Конечное n (аппроксимация Чернова) — доминирует при малых n
   (F0005: E = 3.04 / 0.73 / 0.38 при n = 1 / 2 / 4; порядок не установлен).
2. Усечение T: для точного S хвост ≤ ‖g_R‖∞·tail_eps/2; ‖g_R‖ в T не входит.
3. Квадратура: оценка — разность соседних Nt.
4. Пространство: сплайн; оценка — разность dx и dx/2, включает остаток квадратуры;
   сплайн не гарантирует ‖S‖ ≤ 1 + τC.
5. Оценки 3–4 — индикаторы, а не границы ошибки; из полной ошибки их не вычитать.

## Проверка изменений

- Независимые эталоны: R1 при x = 0 для конечного n (n=1 → 1.48, n=2 → 95/81 = 1.1728395061728395; точное y(0) = 1);
  R1–R5 с точным решением exp(−x²); сгенерированные уравнения с y_exact из загрузчика.
- Метрика: E∞ = max|f − y_exact| на фиксированной целевой сетке, только при success.
- При изменении схемы: прежняя и новая версии на одинаковых config и сетке; при заявленном изменении точности или порядка —
  исследование по одному параметру (n, Nt или dx) при фиксированных остальных.
- Сохранять контракт отказов: при неудаче `f` пуст, failure_reason из существующего набора или новый документированный.
- Инварианты закреплены тестами `test_operator_weights_drift_sign_and_absence_of_lambda` и
  `test_manual_oracles_r1_n1_and_n2`. CLI-тест фиксирует поведение F0000/F0005 при n=1: менять его осознанно, а не подгонкой.
- Улучшения допустимы при обосновании и проверке (кэширование геометрии и сплайнов, квадратура с учётом e^{−λt},
  иная интерполяция, экстраполяция по n и т. п.). Показать эквивалентность или выигрыш по E∞ и по стоимости.
