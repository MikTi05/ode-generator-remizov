# Материалы для научного отчёта на 5–7 страниц

Это **не готовый научный отчёт**.

- FACTS.md — карточки проверенных результатов и ограничений.
- EQUATIONS.md — LaTeX, обозначения, реализованные схемы, два реальных уравнения.
- TABLES.md — две компактные таблицы для основного текста.
- FIGURES/ — четыре рисунка; каждый в PNG400dpi и векторном PDF. Подписи в CAPTIONS.md.
- SOURCES.md — точные пути, конфигурации, границы интерпретации.
- SUPPORT/ — таблицы с полной точностью, исходные финальные ответы, проверки.
- SOURCES_SNAPSHOT/ — автономные копии ключевых документов и исходников.

генератора, один реальный пример, таблицу1, рисунки1–3, ML-таблицу2
и рисунок4, затем ограничения. Второй пример и остальные детали — справочные.
