## Формула квадратуры и проверки до запуска

Используется составной Simpson на неравномерных тройках узлов: интеграл квадратичного
интерполянта для j=0,2,...,N_t-3. При h0=t_(j+1)-t_j, h1=t_(j+2)-t_(j+1), H=h0+h1
локальные веса равны:

- w_j += H/6 * (2-h1/h0);
- w_(j+1) += H^3/(6*h0*h1);
- w_(j+2) += H/6 * (2-h0/h1).

Реализация — chernov_solver.py:125; формирование и накопление — строки 260–277.
Узлы: t_j=T*(j/(N_t-1))^2. При alpha=T/(N_t-1)^2 интервалы равны alpha*(2j+1).
В первой тройке h1/h0=3, поэтому w0=-2*alpha/3. Другие глобальные веса положительны.
Отрицательность первого веса — математическое свойство этой неравномерной формулы,
а не обнаруженная ошибка программы. Алгоритм квадратуры не менялся.

| Проверка | 513 | 1025 |
|---|---:|---:|
| Первый вес | -4.7536819226465264e-5 | -1.1884204806616316e-5 |
| Индексы отрицательных весов | только 0 | только 0 |
| Сумма весов | 18.692237908953764 | 18.692237908953764 |
| sum(weights)-T в float64 | 0 | 0 |

Математически t_old[j]=t_new[2*j]. Здесь совпадение подтвердилось также побайтово
на всех 513 старых узлах. Независимые аналитические моменты 1,t,t^2 проверены;
в данной конфигурации compensated summation воспроизвела их точно в float64.
Для неполиномиальных данных проверено совпадение со scipy.integrate.simpson.
Нарушений формулы и скрытой смены других параметров не обнаружено.
