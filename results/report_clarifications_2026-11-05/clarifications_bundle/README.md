# Уточнения к научному отчёту №2488

Даны ответы на 15 вопросов, готовые математические формулировки и перечень
замен. Текст приложенного отчёта сохранён без редактирования. Пересобраны
только четыре рисунка по уже сохранённым числам: ширина 16.5 см, высота
не больше 20 см, весь текст не мельче 10 пт. Исторические рисунки сохранены.

Выполнены 615 проверок чисел, разбиений, признаков и детерминированного
отбора. Дополнительно сверены 6988 значений распределений, 27 превышений
и четыре строки долей. Все четыре PDF отрендерены Poppler и просмотрены.
При повторной сборке получены те же четыре PDF побайтово.
Новых решений уравнений, траекторий, обучений и предсказаний не выполнялось.

Главные уточнения: выбор 60 уравнений шёл из 700 исходных Train, проверка
продолжения — из 850 уравнений вне Test с 847 доступными ответами Ремизова;
56 отмеченных уверенных побед раскладываются на 53 случая без точного
соперника и 3 сравнения с подтверждённым запасом по времени.

Где проверено:

- `answers.md` — все ответы и готовые замены;
- `facts.json`, `close_cases.csv` — результаты независимого пересчёта;
- `figures/` — четыре PDF с прежними основными именами и PNG для просмотра;
- `figures_verification.json`, `figure_manifest.json` — размеры, шрифты, данные и SHA256;
- `main.attached.tex`, `request.txt` — неизменённые приложения пользователя;
- `plot_data.json` — точная копия сохранённых данных для рисунков;
- `source_hashes.json`, `preservation.json` — источники и сохранность;
- `wording_checks.json` — проверка структуры ответов и слов в готовых формулировках;
- `PROJECT_STATUS.before.md` — статус проекта до дополнения.

Команды проверки из корня проекта (первые две используют локальное окружение;
для последней дополнительно нужен pdfplumber):

```bash
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -B results/report_clarifications_2026-11-05/audit_saved.py
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -B results/report_clarifications_2026-11-05/rebuild_portrait_figures.py
PYTHONDONTWRITEBYTECODE=1 python3 -B results/report_clarifications_2026-11-05/verify_figures.py
```

Для проверки PDF использовано окружение с pdfplumber и pypdf, Poppler 26.05.0.
Рисунки строятся стандартными Matplotlib и NumPy; никаких модулей численных
методов и моделей при построении не импортируется.
