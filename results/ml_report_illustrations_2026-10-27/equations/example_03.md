## Пример 3

Исходное уравнение на всей действительной прямой:

\[a(x)y^{\prime\prime}(x)+b(x)y^\prime(x)+c(x)y(x)=g(x),\qquad x\in\mathbb R.\]

Все числа ниже сохраняют числовые параметры исходной задачи. Вспомогательные функции полностью определены последовательно; неопределённых коэффициентов или подбираемых параметров нет.

Для компактной записи аргумент x у вспомогательных функций опущен.

\[p_{1}=\tanh{\left(0.8244771488423202 x - 1.1456471961460697 \right)}.\]

\[p_{2}=e^{- 0.22106311770162773 \left(x - 1.2370099813399829\right)^{2}}.\]

\[p_{3}=p_{1} p_{2}.\]

\[p_{4}=\frac{1}{0.5987102048642993 \left(x - 0.263931371098713\right)^{2} + 1}.\]

\[p_{5}=\sin{\left(p_{4} \right)}.\]

\[p_{6}=0.5981038935548725 p_{3} + 0.8355110806170926 p_{5}.\]

\[q_{1}=\sin{\left(0.4413832639126721 x + 1.2043497607282871 \right)}.\]

\[q_{2}=\tanh{\left(q_{1} \right)}.\]

\[q_{3}=- \tanh{\left(0.33786109799436775 x + 2.6471811900765823 \right)}.\]

\[q_{4}=-0.2105776416426166.\]

\[q_{5}=- 0.3752371600926675 q_{3} + 0.8908997942655258 q_{4}.\]

\[q_{6}=- 0.28938241805119097 q_{2} - 0.9633684125762357 q_{5}.\]

\[r_{1}=- \sin{\left(0.5744472527325505 x - 2.7408528273199484 \right)}.\]

\[r_{2}=\tanh{\left(r_{1} \right)}.\]

\[r_{3}=\cos{\left(0.2982402651394469 x + 1.7033598802484164 \right)}.\]

\[r_{4}=-0.698604414942803.\]

\[r_{5}=0.493356366191655 r_{3} - 0.8567238179945769 r_{4}.\]

\[r_{6}=r_{2} r_{5}.\]

\[h_{1}=\cos{\left(0.162537284342751 x + 0.4547833238272104 \right)}.\]

\[d_{1}=- 0.162537284342751 \sin{\left(0.162537284342751 x + 0.4547833238272104 \right)}.\]

\[e_{1}=- 0.02641836880151629 \cos{\left(0.162537284342751 x + 0.4547833238272104 \right)}.\]

\[h_{2}=e^{- h_{1}^{2}}.\]

\[d_{2}=- 2 d_{1} h_{1} e^{- h_{1}^{2}}.\]

\[e_{2}=2 d_{1}^{2} \left(2 h_{1}^{2} - 1\right) e^{- h_{1}^{2}} - 2 e_{1} h_{1} e^{- h_{1}^{2}}.\]

\[h_{3}=- \tanh{\left(0.3613725371874747 x + 1.1967457073726797 \right)}.\]

\[d_{3}=0.3613725371874747 \tanh^{2}{\left(0.3613725371874747 x + 1.1967457073726797 \right)} - 0.3613725371874747.\]

\[e_{3}=- 0.26118022126662555 \left(\tanh^{2}{\left(0.3613725371874747 x + 1.1967457073726797 \right)} - 1\right) \tanh{\left(0.3613725371874747 x + 1.1967457073726797 \right)}.\]

\[h_{4}=e^{- 0.46929024038993034 \left(x - 1.3123761993740666\right)^{2}}.\]

\[d_{4}=\left(1.2317706841725578 - 0.9385804807798607 x\right) e^{- 0.46929024038993034 \left(x - 1.3123761993740666\right)^{2}}.\]

\[e_{4}=\left(\left(0.9385804807798607 x - 1.2317706841725578\right)^{2} - 0.9385804807798607\right) e^{- 0.46929024038993034 \left(x - 1.3123761993740666\right)^{2}}.\]

\[h_{5}=- 0.8980719428395056 h_{3} - 0.6907321591909864 h_{4}.\]

\[d_{5}=- 0.8980719428395056 d_{3} - 0.6907321591909864 d_{4}.\]

\[e_{5}=- 0.8980719428395056 e_{3} - 0.6907321591909864 e_{4}.\]

\[h_{6}=h_{2} h_{5}.\]

\[d_{6}=d_{2} h_{5} + d_{5} h_{2}.\]

\[e_{6}=2 d_{2} d_{5} + e_{2} h_{5} + e_{5} h_{2}.\]

\[a(x)=0.16392539473914125 \tanh{\left(p_{6} \right)} + 1.618730489075625,\quad b(x)=1.1248929748256933 \tanh{\left(q_{6} \right)},\quad c(x)=0.857751103852765 \tanh{\left(r_{6} \right)} - 1.2896129579422138.\]

\[z=\frac{x-(-0.03666028004499061)}{1.7373814842542066},\qquad D=1-z^2,\qquad s=6.034151780918269.\]

\[W(x)=\begin{cases}\exp(1-D^{-1}),&|z|<1,\\0,&|z|\ge1,\end{cases}\qquad y(x)=sW(x)h_{6}.\]

\[\ell(x)=-\frac{2z}{1.7373814842542066D^2},\qquad \ell_1(x)=-\frac{2}{(1.7373814842542066)^2D^2}-\frac{8z^2}{(1.7373814842542066)^2D^3}.\]

\[g(x)=\begin{cases}s e^{1-D^{-1}}\left\{a(x)e_{6}+[2a(x)\ell(x)+b(x)]d_{6}+[a(x)(\ell(x)^2+\ell_1(x))+b(x)\ell(x)+c(x)]h_{6}\right\},&|z|<1,\\0,&|z|\ge1.\end{cases}\]

Здесь $d_{6}$ и $e_{6}$ заданы явными формулами выше и равны первой и второй производным $h_{6}$. Таким образом, в правой части нет невычисленных производных.

Границы носителя: -1.7740417642991972 и 1.700721204209216. Гладкое продолжение решения и правой части за носителем равно нулю; коэффициенты определены на всей прямой.

Резольвентная постановка: $L=a(x)\partial_x^2+b(x)\partial_x+c_R(x)$, где

\[\lambda=1.2896129579422138,\quad c_R(x)=c(x)+1.2896129579422138,\quad g_R(x)=-g(x),\qquad(\lambda-L)y=g_R.\]

\[\underline a=1.4548050943364836,\quad\overline a=1.7826558838147661,\quad |b|\le1.1248929748256933,\quad |c_R(x)|\le C=0.857751103852765,\quad\lambda-C\approx0.4318618540894487>0.\]

Оценки $\underline a\le a(x)\le\overline a$, $|b(x)|$ и $C$ глобальны и могут быть неточными; они не названы точными экстремумами.

Ищется ограниченное решение на всей прямой. Отрезок [-1,1] - область сравнения сохранённых численных значений, а не граница определения коэффициентов.

Отдельная совместимая задача Коши на $[-1,1]$ имела бы дополнительные условия

\[y(-1)\approx0.8626576943125405,\qquad y^\prime(-1)\approx1.304418735575674.\]

Эти значения следуют из указанного точного решения. Они не заменяют условие ограниченности в резольвентной задаче; произвольные другие начальные данные определяли бы другую задачу Коши.
