## Пример 2

Исходное уравнение на всей действительной прямой:

\[a(x)y^{\prime\prime}(x)+b(x)y^\prime(x)+c(x)y(x)=g(x),\qquad x\in\mathbb R.\]

Все числа ниже сохраняют числовые параметры исходной задачи. Вспомогательные функции полностью определены последовательно; неопределённых коэффициентов или подбираемых параметров нет.

Для компактной записи аргумент x у вспомогательных функций опущен.

\[p_{1}=\frac{x + 0.21060487890393131}{\sqrt{\left(x + 0.21060487890393131\right)^{2} + 1}}.\]

\[p_{2}=\cos{\left(0.5680183686903811 x + 1.2743887130599818 \right)}.\]

\[p_{3}=- 0.8732132664542837 p_{1} + 1.5298069736612434 p_{2}.\]

\[q_{1}=\frac{x - 0.377349136461925}{\sqrt{\left(x - 0.377349136461925\right)^{2} + 1}}.\]

\[q_{2}=1.000638003655915.\]

\[q_{3}=q_{1} q_{2}.\]

\[r_{1}=\cos{\left(1.00216641136428 x + 0.38109286865906444 \right)}.\]

\[r_{2}=\cos{\left(1.210763323001174 x + 1.2222393183020743 \right)}.\]

\[r_{3}=- 0.8208274553794475 r_{1} - 0.356146361135799 r_{2}.\]

\[h_{1}=\frac{1}{0.638359964281694 \left(x - 0.9052063521362586\right)^{2} + 1}.\]

\[d_{1}=\frac{1.1556949892345292 - 1.276719928563388 x}{\left(0.638359964281694 \left(x - 0.9052063521362586\right)^{2} + 1\right)^{2}}.\]

\[e_{1}=\frac{\frac{\left(1.276719928563388 x - 1.1556949892345292\right) \left(2.553439857126776 x - 2.3113899784690584\right)}{0.638359964281694 \left(x - 0.9052063521362586\right)^{2} + 1} - 1.276719928563388}{\left(0.638359964281694 \left(x - 0.9052063521362586\right)^{2} + 1\right)^{2}}.\]

\[h_{2}=\frac{x + 0.6468874800100536}{\sqrt{\left(x + 0.6468874800100536\right)^{2} + 1}}.\]

\[d_{2}=\frac{\left(- x - 0.6468874800100536\right) \left(x + 0.6468874800100536\right)}{\left(\left(x + 0.6468874800100536\right)^{2} + 1\right)^{\frac{3}{2}}} + \frac{1}{\sqrt{\left(x + 0.6468874800100536\right)^{2} + 1}}.\]

\[e_{2}=\frac{\left(x + 0.6468874800100536\right) \left(\frac{\left(x + 0.6468874800100536\right) \left(3 x + 1.9406624400301609\right)}{\left(x + 0.6468874800100536\right)^{2} + 1} - 3\right)}{\left(\left(x + 0.6468874800100536\right)^{2} + 1\right)^{\frac{3}{2}}}.\]

\[h_{3}=1.5762477906577181 h_{1} + 0.6853099011085214 h_{2}.\]

\[d_{3}=1.5762477906577181 d_{1} + 0.6853099011085214 d_{2}.\]

\[e_{3}=1.5762477906577181 e_{1} + 0.6853099011085214 e_{2}.\]

\[a(x)=0.2713886756098214 \tanh{\left(p_{3} \right)} + 1.4883119432565608,\quad b(x)=0.3669965904808545 \tanh{\left(q_{3} \right)},\quad c(x)=0.7166536787465632 \tanh{\left(r_{3} \right)} - 1.1821619224255704.\]

\[z=\frac{x-(-0.12615575192036316)}{2.5739978197604607},\qquad D=1-z^2,\qquad s=0.4908742162816097.\]

\[W(x)=\begin{cases}\exp(1-D^{-1}),&|z|<1,\\0,&|z|\ge1,\end{cases}\qquad y(x)=sW(x)h_{3}.\]

\[\ell(x)=-\frac{2z}{2.5739978197604607D^2},\qquad \ell_1(x)=-\frac{2}{(2.5739978197604607)^2D^2}-\frac{8z^2}{(2.5739978197604607)^2D^3}.\]

\[g(x)=\begin{cases}s e^{1-D^{-1}}\left\{a(x)e_{3}+[2a(x)\ell(x)+b(x)]d_{3}+[a(x)(\ell(x)^2+\ell_1(x))+b(x)\ell(x)+c(x)]h_{3}\right\},&|z|<1,\\0,&|z|\ge1.\end{cases}\]

Здесь $d_{3}$ и $e_{3}$ заданы явными формулами выше и равны первой и второй производным $h_{3}$. Таким образом, в правой части нет невычисленных производных.

Границы носителя: -2.700153571680824 и 2.4478420678400976. Гладкое продолжение решения и правой части за носителем равно нулю; коэффициенты определены на всей прямой.

Резольвентная постановка: $L=a(x)\partial_x^2+b(x)\partial_x+c_R(x)$, где

\[\lambda=1.1821619224255704,\quad c_R(x)=c(x)+1.1821619224255704,\quad g_R(x)=-g(x),\qquad(\lambda-L)y=g_R.\]

\[\underline a=1.2169232676467394,\quad\overline a=1.7597006188663822,\quad |b|\le0.3669965904808545,\quad |c_R(x)|\le C=0.7166536787465632,\quad\lambda-C\approx0.46550824367900734>0.\]

Оценки $\underline a\le a(x)\le\overline a$, $|b(x)|$ и $C$ глобальны и могут быть неточными; они не названы точными экстремумами.

Ищется ограниченное решение на всей прямой. Отрезок [-1,1] - область сравнения сохранённых численных значений, а не граница определения коэффициентов.

Отдельная совместимая задача Коши на $[-1,1]$ имела бы дополнительные условия

\[y(-1)\approx0.10643772906019516,\qquad y^\prime(-1)\approx0.43361196045069755.\]

Эти значения следуют из указанного точного решения. Они не заменяют условие ограниченности в резольвентной задаче; произвольные другие начальные данные определяли бы другую задачу Коши.
