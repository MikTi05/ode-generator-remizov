# Наблюдения, полезные для обсуждения рисунков


**Пример 1.** Постоянны именно a, b и c, но не правая часть: она содержит
производные известного компактно поддержанного решения. Внутри отрезка
сравнения видно положительное асимметричное решение. Максимальная MC-ошибка
0,0102624 находится чуть выше допуска: округление до 0,01 недопустимо для
принятия решения о точности. Выбор более дорогого точного приближения здесь
иллюстрирует неоптимальность по времени, а не ошибку точности.

**Пример 2.** Коэффициенты меняются плавно, решение на отрезке возрастает к
широкому максимуму. Оба изученных числа итераций дают ошибку заметно ниже
порога. Это реальный пример экономного точного выбора модели; гладкость
графиков сама по себе не доказывает достижимость допуска для других задач.

**Пример 3.** Изменение коэффициентов визуально умеренное; максимум ошибки
меньшего приближения расположен ближе к правой части отрезка и лишь немного
превышает допуск. Уточнение действительно пересекает порог. Не следует
выводить из этого единичного наблюдения причинную связь между плавностью
коэффициентов, положением максимума и погрешностью.

**Пример 4.** Видны неодинаковые масштабы изменения коэффициентов и смена
знака точного решения внутри отрезка. Обе кривые Ремизова почти совпадают с
точной на общем масштабе, однако максимум ошибки меньшего приближения
нарушает допуск. Соответствующий сохранённый ответ Монте-Карло также показан,
а не исключён из сравнения.

**Пример 5.** Точное решение имеет несколько локальных экстремумов и меняет
знак. На части узлов уточнённая ошибка ниже допуска, но её максимум остаётся
выше. Этот рисунок особенно полезен для различения локального совпадения
и требования к максимуму на всех 33 узлах. По двум приближениям нельзя
разделить ошибки квадратуры, пространства, конечного числа итераций и хвоста.

**Пример 6.** Осциллирующие коэффициенты и локализованные особенности правой
части видны непосредственно на рисунке. Меньшая из двух максимальных ошибок
около 0,0111 - всё ещё нарушение допуска. Внешняя близость кривых решений
не позволяет объявить точность. Продолжение с большим числом итераций здесь
не проверялось, и порядок сходимости не установлен.

**Пример 7.** В одном ранее выполненном временном блоке Монте-Карло быстрее
двух приближений Ремизова, но только одна из четырёх реализаций достигает
допуска. Во всех четырёх повторах метод Ремизова с меньшим числом итераций
точен. Это иллюстрация различия между наблюдаемым успешным быстрым ответом
и надёжным выбором следующего запуска; не доказательство надёжного MC-преимущества.
