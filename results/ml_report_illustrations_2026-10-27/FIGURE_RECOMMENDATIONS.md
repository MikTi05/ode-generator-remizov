# Отбор иллюстраций для будущего текста

## Основной текст: рекомендуемый компактный набор

- **Рисунок 31:** стоимость и число точных доставок на всех 60 семействах.
  Центральный результат; не заменять его процентом ускорения без точности.
- **Рисунок 33:** точные, неоптимальные по времени и неточные выборы.
  Видны 34 случая излишне дорогого точного приближения и 3 неточных ответа.
- **Рисунок 12:** ошибка примера 3. Видно пересечение допуска при уточнении;
  для демонстрации полной постановки достаточно формул этого примера.
- **Рисунок 20:** ошибка примера 5. Показывает, почему локальное попадание
  ниже допуска не обеспечивает требование к максимуму на всей сетке.
- **Рисунок 29:** четыре реализации Монте-Карло на ранее исследованном
  уравнении. Использовать вместе с явным результатом 0/20 финальной проверки.
  Один удачный ответ не представлять доказанным преимуществом метода.

Если доступно восемь страниц, **рисунок 30** с распределениями ошибок можно
добавить в основной текст. Нельзя сравнивать доли Монте-Карло с другими
линиями, забыв разные знаменатели 20 и 60.

## Приложение

Рисунки 1-4 раскрывают простой пример с постоянными коэффициентами; особенно
полезен рисунок 4 с MC-ошибкой чуть выше допуска. Рисунки 5-8 показывают точный
ответ при переменных коэффициентах. Рисунки 9-16 дополняют случаи успешного
уточнения; 17-24 раскрывают два случая нарушения порога. Рисунки 25-28 дают
математический контекст исторического опыта. Рисунок 32 содержит парные
измерения и накопленную стоимость, рисунок 34 - отдельные MC-ошибки и времена.

Точные решения на носителе (2, 6, 10, 14, 18, 22, 26) полезны для объяснения
ограниченности на ℝ и отличия носителя решения от отрезка сравнения. Обычно
достаточно одного такого рисунка, остальные оставить для приложения.

Наличие колебаний или контраста на рисунке не доказывает их причинную роль
в ошибке. По двум значениям числа итераций нельзя устанавливать порядок
сходимости. По одной реализации нельзя оценивать устойчивость времени или
надёжность следующего случайного запуска.
