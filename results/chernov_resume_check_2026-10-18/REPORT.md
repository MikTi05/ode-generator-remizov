# Проверка безопасного возобновления solve, 2026-10-18

Проверка остановки/продолжения на трёх настоящих pending **прошла**. Обработаны
ровно AMV1_F0138_S01, S02, S03, все три достигли E∞≤0.01. Сейчас расчёт
остановлен: 697 терминальных записей, 303 pending. Вся оставшаяся серия не
запускалась. Старые 691 конечный ответ и 3 worker_exception не пересчитывались.

## Протокол и область вывода

[plan.json](plan.json) сохранён до численных запусков. Выбраны первые три pending
исходного плана без обращения к ошибкам/exact для выбора параметров: это три
параметризации одного семейства F0138, сложность L3, режим oscillatory.
Проверяется жизненный цикл, сохранение и возобновление, а не разнообразие
точности/теплового поведения на всех оставшихся уравнениях.

Использован только `chernov_solver.ChernovSolver.solve`, прежняя конфигурация:
n=128, num_t=513, quadratic, dx=0.0125, padding=12, cubic+taper,
tail_eps=1e-8, n_jobs=1, BLAS=1, max_work_grid_points=100000. T автоматически
вычисляется по сертификатам, не по точному решению; n_steps=32768 сохранён
в конфигурации, но относится к другой схеме. Проверка E∞ на прежней сетке
33 точек [-1,1]; exact используется только после solve. Разрешение владельца
120 с не менялось и не продлевалось автоматически.

Полные входные/выходные массивы, параметры, времена и счётчики сохранены в
`../chernov_solve1000_2026-10-18/solutions/<ID>.json` и в соответствующих attempts.

очистку. Повторного решения завершённых задач не было. Прерванная попытка S02

по SDK неподдерживаемая/неизвестная система также может вернуть nominal.

нагревом**. Это ограничение сохранено в плане, коде и инструкции.

## Команда следующей отдельной партии

Только после указания пользователя, из корня проекта, с наблюдением за выводом
и нагревом ноутбука:

```bash
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -B diagnostics/chernov_monitored_batch.py \
  --output-dir results/chernov_solve1000_2026-10-18 \
  --run --max-new 3 --thermal-state-only
```

Остановка — Ctrl+C либо из другого терминала:

```bash
.venv/bin/python -B diagnostics/run_chernov_batch.py \
  --output-dir results/chernov_solve1000_2026-10-18 --stop
```

Следующий вызов той же команды продолжит pending, пропуская все терминальные
итоги, включая три прежних отказа. Между партиями ≥60 с и проверка нагрева;
120-секундное внешнее разрешение остаётся действующим, автоматического
`--keep-alive` нет. Полная оставшаяся серия без подтверждения не запускается.
Подробная инструкция: [CHERNOV_BATCH_EXECUTION.md](../../docs/CHERNOV_BATCH_EXECUTION.md).
