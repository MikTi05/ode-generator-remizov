# Редактируемый исходник третьей части отчёта №2488

report.tex — основной файл, preamble.tex — оформление, sections/ — текст,
figures/ — все 34 векторных рисунка, fonts/ — четыре используемых шрифта.
Исходник автономен: Python, модели и решатели для сборки не нужны.

Сборка из этого каталога: tectonic report.tex
Либо два прохода xelatex report.tex для корректных перекрёстных ссылок.
Проверено Tectonic 0.17: 8 страниц основного текста + 40 страниц приложений.
Для первой сборки движку могут потребоваться стандартные TeX-пакеты.

SOURCES.md — отдельный внутренний указатель данных и методов проверки;
он не включён в научный PDF. SHA256.json позволяет проверить исходник.
Новые численные решения и обучение при подготовке отчёта не выполнялись.
