# Простые графики ML-эксперимента

Ключевые выводы по графикам:

- На всех 997 задачах чаще побеждает R128: 826 случаев против 106 у MC mean4 и 65 у PI.
- На Test ML уступает постоянному R128 по Accuracy (88,67% против 90,67%) и Macro-F1 (0,3144 против 0,3170).
- По средней ошибке среди постоянных решений лучше MC mean4: 0,017275; у ML средняя ошибка 1,658850.
- Модель не распознала ни одной из 14 Test-побед MC/PI; полезное улучшение выбора трёх методов не подтверждено.
- Наибольшая сохранённая importance у b_rms; это описание модели, а не доказательство причинности.
