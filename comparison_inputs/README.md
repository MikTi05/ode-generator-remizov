# Исходные материалы Chern

`Chern.py` и `example.ipynb` скопированы побайтово из файлов, предоставленных
пользователем 2026-10-18. Источник и SHA-256 записаны в `provenance.json`.
Это сохранённая исходная версия, а не рабочая точка входа проекта.

Адаптация находится в `../chernov_solver.py`. Исходный `remizov_solver.py`
сохранён без изменений. Ноутбук не выполнялся; независимые проверки адаптации
находятся в `../tests/test_chernov_solver.py`.
