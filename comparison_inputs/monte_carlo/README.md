# Метод Монте-Карло для нашей задачи: схема работы

В папке:

| файл | что это |
|---|---|
| `mc_solver.py` | солвер: функция `solve(...)` |
| `example.ipynb` | простой пример использования солвера по шагам, с графиком |

## 1. Задача

Ищем ограниченное решение $f$ на всей прямой:

$$
a(x)f''(x) + b(x)f'(x) + \bigl(c(x)-\lambda\bigr)f(x) = -g(x),\qquad x\in\mathbb R .
$$

Условия: $a(x)\ge a_0>0$; функции $a,b,c,g$ ограничены; $\lambda>\sup|c|$.

Метод даёт **значение $f$ в одной точке $x_0$**. Чтобы получить $f$ в нескольких точках, расчёт повторяется для каждой.

## 2. Формула, по которой считаем

$$
f(x_0)=\mathbb E\int_0^\infty e^{-\lambda t+\int_0^t c(X_s)\,ds}\;g(X_t)\,dt ,
$$

где $X_t$ — случайная траектория, которая стартует в $x_0$ и движется по правилу

$$
dX = b(X)\,dt + \sqrt{2a(X)}\,dW .
$$

Словами: из точки $x_0$ запускаем много случайных блужданий. Вдоль каждого накапливаем значения $g$ с весом $e^{-\lambda t}$, умноженным на $e^{\int c}$. Затем усредняем по блужданиям.

## 3. Алгоритм

Входные данные: $a,b,c,g,\lambda$, точка $x_0$, число траекторий $M$, шаг по времени $\Delta t$.

1. **Верхний предел по времени.** Бесконечный интеграл обрезаем на $T$:
   $$\delta=\lambda-\sup|c|,\qquad T=\frac1\delta\ln\frac{2}{\delta\,\varepsilon_T}.$$
   Здесь $\varepsilon_T$ — допустимая ошибка от обрезания, по умолчанию $10^{-4}$. Число шагов $N=T/\Delta t$.
2. **Запускаем $M$ траекторий одновременно** (это массив длины $M$). Начальные значения: $X^{(0)}=x_0$, $I^{(0)}=0$ (накопленный $\int c$), $S=\tfrac{\Delta t}{2}\,g(x_0)$.
3. **Шаг $k=1,\dots,N$** (схема Эйлера–Маруямы):
   $$X^{(k)} = X^{(k-1)} + b(X^{(k-1)})\,\Delta t + \sqrt{2a(X^{(k-1)})\,\Delta t}\;\xi,\qquad \xi\sim\mathcal N(0,1),$$
   $$I^{(k)} = I^{(k-1)} + \tfrac{\Delta t}{2}\bigl(c(X^{(k-1)})+c(X^{(k)})\bigr),$$
   $$S \mathrel{+}= w_k\, e^{-\lambda k\Delta t + I^{(k)}}\, g(X^{(k)}),$$
   где $w_k=\Delta t$, а на последнем шаге $w_N=\Delta t/2$. Это формула трапеций по $t$.
4. **Результат.** После $N$ шагов у каждой траектории своё число $S_j$:
   $$f(x_0)\approx \bar S=\frac1M\sum_{j=1}^M S_j,\qquad
   \text{погрешность }\pm 1.96\,\frac{\operatorname{std}(S_j)}{\sqrt M}\ \ (95\%).$$

Всё это — функция `path_contributions` в `mc_solver.py`, около 20 строк. Функция `solve` добавляет к ней выбор $T$, счёт порциями (чтобы не занимать много памяти) и подсчёт погрешности.
